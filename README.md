## Сохранённое взаимодействие

- Фото ткани с ограниченным параллаксом; нативный drag изображения отключён.
- «Ваш образ»: готовые силуэты, цвет и повод, сводка идеи и переход к демоформе.
- «Поймать оттенок»: рабочие кнопки 01–03 сохраняют значения и результат каждого образца в памяти текущего сеанса страницы.
  Победа требует трёх различных образцов; перезапуск очищает попытки.
- Основные блоки реагируют на курсор; цели и поля остаются на месте.
- Стрелки CTA направлены вверх-вправо и становятся горизонтальными вправо при hover/focus.
- Закреплённая кнопка «Контакты», акцентные звонок и Telegram, выделение только цветом букв, клавиатура, touch и reduced-motion сохранены.
- Демоформа валидирует ввод, честно показывает эмуляцию, очищает данные и позволяет повторить.
